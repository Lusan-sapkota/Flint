In tokens. Raise the local one if your GPU has the memory; a bigger window keeps more of a long chat but uses more memory and is slower. A cloud model costs no local memory, but each turn resends up to its window, which counts against your ollama.com usage. No model is given more than it supports.

How many @agent subtasks run at the same time; the rest wait their turn. Each agent is one more request to the model at once. Locally they only truly run together if Ollama allows it (OLLAMA_NUM_PARALLEL at least this high); otherwise Ollama runs them one after another, and each parallel request needs its own context-window memory on the GPU. Commands per agent caps how many shell commands one agent may ask you to approve while it looks through the folder; it also stops sooner when its window is full or after 3 failed or denied commands in a row.

Profile

Password

Forgot your current password? Log out and use Forgot your password? on the login page. That works only if you've set security questions, which you can do below.

Security questions

Used to recover your account without email. Answers are never shown back to you once saved. Saving this form replaces all questions and requires re-entering every answer, even ones you're keeping.

Delete account

Deletes your account and everything in it: chats, attachments, memories and settings. This cannot be undone. Enter your password and the answers to your security questions to confirm.

Updating

Flint never checks for updates on its own, so nothing leaves this machine. Update when you choose; your chats and settings are kept.

Docker, in the folder with your compose file:

sh
docker compose pull && docker compose up -d

From source:

sh
git switch main && git pull
cd backend && go run .

To hear about new releases, watch the repository on GitHub (Watch → Custom → Releases).
